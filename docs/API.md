# API

Base URL (development): `http://localhost:8000`. All application endpoints are versioned under
`/api/v1` (`settings.api_v1_prefix`). Interactive docs are auto-generated by FastAPI at `/docs`
(Swagger UI) and `/redoc`; raw schema at `/openapi.json`.

## Versioning strategy

Every route lives under `/api/v1/...`, aggregated in
[`presentation/api/v1/router.py`](../backend/src/app/presentation/api/v1/router.py). A future
breaking change gets a new `presentation/api/v2/` package and router, mounted alongside v1 rather
than replacing it — existing clients keep working.

## Endpoints (Stage 0)

### `GET /api/v1/health`

Liveness check. Deliberately has **no database dependency**, so it stays meaningful even if
Postgres is down.

Response `200`:
```json
{
  "status": "ok",
  "service": "Legal Document & Matter Management System",
  "environment": "development",
  "timestamp": "2026-08-05T04:24:37.276325+00:00"
}
```

### `GET /api/v1/version`

Reports the running build.

Response `200`:
```json
{
  "app_name": "Legal Document & Matter Management System",
  "version": "0.1.0",
  "api_prefix": "/api/v1"
}
```

## Cross-cutting behavior

- **CORS**: allowed origins come from `Settings.cors_origins` (`CORS_ORIGINS` env var,
  comma-separated) — defaults to the Vite dev server origins. Configured in `main.py` via
  `CORSMiddleware`.
- **Request correlation**: `RequestIDMiddleware` assigns (or reuses) an `X-Request-ID` header on
  every request/response and stores it on `request.state.request_id`; `LoggingMiddleware` logs one
  structured JSON line per request including that ID, method, path, status, and duration.
- **Error shape**: every error response — whether a deliberately raised `AppError` subclass, a
  FastAPI validation error, or a genuinely unexpected exception — has the same JSON shape:
  ```json
  { "error": { "code": "not_found", "message": "..." } }
  ```
  See [`presentation/middleware/error_handler.py`](../backend/src/app/presentation/middleware/error_handler.py)
  and [`application/errors/exceptions.py`](../backend/src/app/application/errors/exceptions.py).
